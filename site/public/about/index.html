About This Blog

This is a minimalist tech blog where I explore software development, share tutorials, review tools, and dive deep into technical topics that interest me.

The Stack

This blog is built with:

  • Hugo - A fast static site generator
  • Hugo XMin - An extremely minimal theme (~140 lines of code)
  • Decap CMS - For content management
  • Syntax highlighting powered by Chroma

The focus is on simplicity, speed, and content. No JavaScript frameworks, no bloat—just clean HTML, minimal CSS, and well-formatted content.

Contact

Feel free to reach out or contribute via GitHub.

Philosophy

“Simplicity is the ultimate sophistication.” - Leonardo da Vinci

I believe in:

  • Writing clear, maintainable code
  • Understanding fundamentals over chasing frameworks
  • Sharing knowledge openly
  • Keeping things simple and focused
